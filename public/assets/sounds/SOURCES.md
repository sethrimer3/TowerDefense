# Sound sources

Each file's original upload, by its new name. The creator prefixes and ids
look like Pixabay downloads; those without one were named by hand. One-shots
were peak-normalized to -1 dBFS; loops were loudness-matched (-20 LUFS) and
the long ones trimmed to the stretch noted (the game cross-fades each loop's
end into its start, so they repeat without a seam). The untrimmed originals
are in git history, in the commit "Sound effects".
