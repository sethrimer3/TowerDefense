# Ambush local gold upgrades
- Panel: the selected native building in Ambush's sidebar; all native nextSteps choices, including merges that consume two actual maxed partners.
- Currency: only this level's gold. No Mine metals, Knowledge, Smithy or Defend inventory is read or spent.
- Prices (initial tuning): attunement 55% of estimated base price; branch attunement 70%; path ranks I/II/III 40/65/100%; merge 150%; beyond-ultimate 200%. Round each fee to tens, minimum 20 gold. Fees use the native catalog's potential-DPS estimate, not native Knowledge prices.
- Investment includes purchase, every upgrade fee and both consumed merge partners. Refund is full until wave 2 starts, then floor(70% / 10) × 10, modified only by Ambush's future Quartermaster ranks.
- Kind changes retrain native troops in the same stable home, preserve the building's HP fraction and validate its new footprint before spending. Path ranks use per-home native battle snapshots.
- Statistics: native post-mitigation damage clamped to remaining HP, one killing hit, including splash and captured burn/venom/bleed origins. Dead shooters retain their home for in-flight projectiles. The panel updates at most four times per second.
- Permanent power: none in this phase; the Ambush-only star tree follows separately. Prices remain rough until the balance script.
